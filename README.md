# Inverted Pendulum
An inverted pendulum control system developed as a fourth-semester project at the University of Southern Denmark (SDU).

The system uses a motor-driven cart to balance a pendulum in an upright position. The project combines modelling, control theory, simulation, and PLC programming (Schneider).

## Features
- Mathematical modelling of the inverted pendulum
- Equations of motion derived from the physical system
- Linearized state-space model and transfer functions
- PID controller design and tuning
- Classical control theory strategies: cascade and parallel
- Modern control theory
- Simulation in Simulink and Simscape
- Schneider PLC control system implementation


## Technologies
- MATLAB
- Simulink
- Simscape
- Schneider PLC (Structured Text)
